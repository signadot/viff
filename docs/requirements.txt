# These two move TOGETHER, and tony-format found out the hard way: Pygments 2.20.0 escapes the
# HTML formatter's `filename` option, which pymdown-extensions 10.17.1 passes as None for a
# fenced block whose first line is blank and whose body is indented — `mkdocs build` then exits
# 1 without writing a page. 11.0.1 is the release that stopped passing None. Pinning Pygments
# is the point: it was the one dependency left resolving on its own, so a fresh install here
# would have picked up 2.20.0 against the old pymdown-extensions and broken for the next person
# rather than for whoever changed something.
