## Decided (2026-10-31): an install returns once accepted, and waits only when asked

- **Accepted** means the records are written and the charter check passed. Every refusal that won't succeed later is still made here, synchronously: a malformed rule, a `reads` it breaks, a spawn no runner takes. The atomic step is the write plus the check. Arming is the reconciler's, and it can be pending only for reasons that can clear.
- **The default is not to wait, for every caller**, a person at the CLI included. The answer gives each package's armed and pending counts at that moment ("7 rules; 2 arming").
- **Waiting is asked for**: `verse charter -a --wait[=<duration>]`. It blocks until the package's rules are armed or the duration runs out, and on timeout answers what's pending and why, with an exit code of its own, so a script can tell pending from refused.
- **MCP and the tools stay aligned with the CLI**: `verse_charter_install` and the verse system's `charter-install` take the same `wait` with the same default and the same answer. The API takes it too, since all of them are built on it.
- `-check` is unchanged.

What follows from it:
- The repo-charters live-check compares the **records** with verse/live, not the engine, so #37 doesn't open while rules are arming. Whether arming is done is status's to say.
- Tests that install and then write expect the rule armed. They wait through a helper, rewritten outright, with no compatibility shim.
- A write right after a no-wait install isn't lost: the rule's watch opens with what stands, so the rule sees it as initial state when it arms. An edge between accepted and armed (a value set and cleared again) is not seen. The same window exists today between an install's start and its watch opening, and the queue only makes it longer.
- `systemWaiting` (versed/server.go:4031), the system charters retried only when an iod registers, becomes one more path into the reconciler's queue. `repo-charters.cli`'s 0 rules on staging since 08:30 today is probably that: its re-install timed out at start and nothing has retried it. Unconfirmed.
