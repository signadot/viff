Second review's fixes: 7b9cfaf3 on verse/mcp (local, unpushed).

- **Logins.** The copy and re-exec from 27e3d137 are gone. `bearer` re-reads the tokens file at each request, and again before saving a renewal, and the renewal changes only its own (verse, provider) entry. A long-running `verse mcp` sees logins, logouts and rotated refresh tokens from other processes, and doesn't clobber them. Not addressed: two renewals racing in the same instant, since there is no file lock. Further work on long-running auth is punted.
- **verse_wait.** Cursors are `<server>.<seq>`, so any cursor from an earlier server is refused.
- **verse_task_events.** A part never ends at a mid-stream gap. A frame over 1 MiB is reported as an error, here and in `task attach`, instead of looping.
- **Ids.** The per-task tools refuse an empty id or one containing `/`. `client.URL` already escapes, so `url.PathEscape` would double-encode. The ask.go uses on main do exactly that.
- **Reuse.** `taskEnded` goes through `taskSnapshotVia`, and `verse_question` through `questionQuery`, both shared with the CLI.
