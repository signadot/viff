**Decided: a veto is an answer to verse's ask, wherever it is given.** (2026-10-01)

Readiness is an ask settling `proceed`. The review system surfaces the ask as one more interface beside Slack and the CLI, and an objection made there is an answer to the ask, recorded with a name. So the open question in part 3, "is a veto read from the review instance or only from verse's own gate?", is a false choice. There is one record, the ask, and there are several places to answer it. A review io's job is to put the ask in front of reviewers and carry their answers back. It does not supply a second source of vetoes.

Also: trial tags are spelled `verse/trial-<nonce>` (the body still says `verse-sandbox-<nonce>`), and two-way chat in the review system is a nice to have.
