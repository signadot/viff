Second review round (one /code-review high pass over main...verse/pkg) returned nine findings, all in the installer's path; fixed in fab392d7 on verse/pkg.

The findings, and what fixed each:

1. **Epoch versions misread** — the Inst-line regexp dropped `1:` epochs, so fetch keyed the wrong version. One regexp now keeps the version whole.
2. **`:arch` qualifiers leaked into closure names** — `git-man:amd64` never matched the index. The closure strips the qualifier; the refusal checks read the bare name.
3. **URLs joined by position** — three apt outputs (plan, index, --print-uris) were zipped by order; a reordering misfiled a URL. URLs now key by name+version decoded from the --print-uris destination filename (`%3a` unescaped).
4. **A libc upgrade bundled a libc the loader can't run** — a plan that moves libc6/libc6-* is refused by name with "a newer image carries it". Other upgrades (pinned-newer named package, dep upgrades) still bundle — that's the design.
5. **Private-tree packages installed broken** — programs under usr/libexec, usr/games, opt, or loose non-.so files under lib dirs don't work laid flat. `carriable` refuses after extraction, naming the offending path.
6. **sbin dropped** — usr/sbin and sbin now land in bin.
7. **Unreadable candidate skipped silently in the runpath pass** — an isELF read error now fails the build naming the file ("for its runpath").
8. **Installed.As held a joined list of commands** — split into As (the one renamed command) and Commands (own names landed); the answer says which case: renamed, listed on PATH, or the image's own.
9. **Name rule duplicated** — ReadInstall had its own copy of the cellar's name check, drifting. cellar.CheckName exported and used; one rule where the path segments are made. Plus: the cellar caches a prefix's size (walked once, immutable; entry dropped on evict) and stock's pkgDoer helper is gone.

Tests added: epoch/arch/URL/libc resolve test, private-tree + sbin + unreadable-ELF build test, cellar size-cache test, installer As/Commands expectations. docs/systems/pkg.md updated for the libc and flat-prefix refusals.

A third round is running in parallel over the stack including these fixes; its findings will land here.
