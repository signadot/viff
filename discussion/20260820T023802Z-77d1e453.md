PARTLY UNBLOCKED, and the remaining obstacle is now a concrete one rather than a general one.

The reason this issue stalled is the charter's own: "a static call list cannot carry a dynamic
set", so `train-run` scans the clone instead of being handed the branches the docket listed. Half
of that was `$subject.value.x` not resolving in a string at all, which is fixed
(`e1016113`). The list now reaches the command:

    $subject.value.branches  →  "- refs/remotes/mirror/verse/auto/x/1\n- refs/remotes/mirror/verse/auto/y/2"

WHICH IS TONY, NOT A SHELL WORD LIST. `bindText` renders a composite as tony — deliberately, and
it is the right default for a prompt — so dropped into `for b in $subject.value.branches` it
gives the shell a leading `- ` on every element and a newline between them. Also checked:
`$subject.value.branches[0]` binds to nothing, since the flat map walks objects and not array
indices.

So the three shapes actually available today, all of them the charter's own decision:

1. STRIP IT IN THE SHELL — `for b in $(printf '%s' "…" | sed 's/^- //')`. Works now, and puts a
   tony-rendering assumption inside a shell string, which is the kind of thing that breaks
   quietly when the rendering changes.
2. BIND ARRAY ELEMENTS, so `$subject.value.branches[0]` resolves. Small change to the binding
   walk, and it still does not give a loop over a set whose SIZE is dynamic — which is the thing
   this issue is about.
3. HAND THE LIST TO THE CALL AS A LIST rather than through the command string. `bindCalls`
   expands each argument in place and its comment already draws exactly this distinction ("a list
   in a field" versus "a list inside the prompt"), so a tool taking a `branches` argument would
   get a real list, with no quoting or rendering in the way. This is the one that matches what the
   issue asks for, and it needs a tool that takes it.

I have not made the charter change. It alters what a live merge train does with a credential, on
a drive whose ground is `main`, and the choice between the three above is a design decision about
what `train-run` should be handed — not something to land on somebody's behalf.

Leaving open, with the blocker halved and the options costed.
