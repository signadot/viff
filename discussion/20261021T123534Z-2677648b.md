**New step 6a′, before 6b: the empty block** (scratchpad/empty-block-shorthand.md, agreed 2026-10-21).

- **Consequences:**

  - The deploy ceilings and the shipped charters' inner systems shrink to `{}`.
  - Docs state the rule, the guard and the convention that a shipped charter writes its git push shapes.
