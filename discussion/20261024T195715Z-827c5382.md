Design review of the page against the code on the branch (2026-10-24), and what it changed.

Confirmed from the code: a token versed mints toward a runner opens nothing at versed's own door (the door finds a verifier by `iss`, and versed's issuer url is no provider); the runner's `ca` reaches the key fetch; the hello is admitted by the door before its handler, one describe in flight per registration; the relay the system page needs is feasible from the task record as it stands (`runnerName`, and the record's writer as the owner).

Five findings, all applied:

1. The runner's trust anchor is the url it fetches keys from, not "the key": over plain http in-cluster, whoever answers at `verse.url` is the runner's verse, and a party on the path versed→runner gets the minted bearer and, at the describe, the runner's own token (control of that runner's tasks). Same anchor class as iods toward the cluster issuer, which travel over TLS. Stated on the page; `verse.ca`/TLS closes it; deployment work.
2. Rotation: versed reads its key at start (`cmd/verse/up.go`), so rotating is replace entry, sync, roll versed; old-key tokens die at the restart. The ExternalSecret comment and the page say so now.
3. Two invariants were held by order alone: a config naming a registered runner's subject as an iod account won at the door silently (the reverse is refused at add); and nothing refused `auth.issuer.url` equal to a provider's issuer or the workload issuer. Now `setIod` refuses the first (a failed read refuses too) and the config validator the second. Commit 7937e54cf.
4. System page: the owner for the relay is the identity that wrote the task record, never the spawn's self-asserted `principal` field; the comparison is on `runnerName` (`runner` is the url).
5. `Verse-For-Principal` names an account at a provider and is parsed as one; the relay names the task in its own header, `Verse-Task`. Decided on both pages for the verbs PR.

Noted, no change: a runner whose registration is removed announces every 30s forever (one log line each); the event stream outlives the ten-minute token, bearer checked at connect; the bare describe is public by design.
