**The plan, agreed 2026-11-09.** The three open questions, decided:

1. **Same socket, no third.** The I/O pair is already a bidirectional unix stream socket: stdout flows runner→task on it today, stdin flows task→runner on the same pair. The stderr pair stays the untouched let-go detector, so kill semantics do not change. The task half-closes its end (`CloseWrite`) to say stdin is done while still reading stdout — how a `jq`/`gpg`-style command sees EOF.
2. **No redaction on the way in**, and the words say so: input goes to the process that already holds the secret.
3. **Opt-in by a `stdin` bool field on `secret.exec`, default `false`.** Shapes are read with defaults filled in, so every existing environment and ceiling reads as `{stdin: false}` and an interactive call is outside until a shape names `stdin`. The step always carries `stdin`, so an approver sees they are approving a session, not one argv; rows name what they name, so existing rows are untouched.

How it is built:

- **Runner (`delivery/secret.go`)**: `Exec` gains `Stdin`; `ReadExec` reads it, `Step()` carries it. In `runSecret`, when set: `cmd.StdinPipe()` before Start and a goroutine `io.Copy(pw, ioNear)`, closed on EOF — not `cmd.Stdin = ioNear`, whose exec-owned copy would hold every `Wait` on the socket until WaitDelay. The existing `ioNear.Close()` at the run's end reaps the goroutine.
- **Task (`stock/secrettools.go`)**: `secret-exec` gains a `stdin` boolean; when true the tool serves `<id>.in.sock` beside the two outputs. The first connection is the input, pumped into the I/O end, its close the half-close; input mirrored to `.verse/exec/<id>.in` (same cut as the outputs) so the read plane keeps what the command was fed. Kill/let-go closes the listener too. With `stdin: true` and nobody connecting, the command's stdin stays open — the timeout is the bound, and the words say it.
- **Docs**: the input passage in `docs/systems/secret.md` and the tool's description.
- **Tests**: delivery (an interactive run round-trips bytes, output still redacted, half-close ends the command; a plain run unchanged), systems (a shape naming nothing refuses `stdin: true`; `{stdin: null}` admits), stock (the in.sock end-to-end).
