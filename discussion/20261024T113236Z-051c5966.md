## Code-level plan

**Files:** `deploy/charters/example/repo/app/stale-review.tony` and a `stale-review.md` README beside it (the existing README is comment-drift's).

**Head**
- `at: signadot.stale-review`, `reads: [github, verse.schedule]`.
- `schedules: [{name: morning, every: 24h, from: <a weekday 09:00 in the zone>}]`; the rule skips Saturday and Sunday by the tick's `weekday`.
- Strata: `day` for `signadot.stale-review.day.*`, and one for the out place, `slack.Signadot.out`, as gate-ask.tony declares it.

**Rules**
1. `gather` on `verse.schedule."signadot.stale-review:morning".tick.*`, weekday only: derive `signadot.stale-review.day.<date>` with `prs: !list-paths {at: "github.signadot.signadot.pr.*", value: {state: open, requestedReviewers: !subtree <login>}, path: number}`. A tick needs no latch; the day entity is keyed by date, so a re-fire rewrites the same bytes.
2. `review` on `signadot.stale-review.day.*` with `prs` non-empty and no `stage`: spawn on `verse.runners.claude`, agent `claude`.
   - Environment: `git: [{repo: example/app, from: master, fetch: {}}]` (no push; the checkout is what the read verbs need until z85vx3z2), `github: [{repo: example/app, read-pr: {}, list-prs: {}}]`, `network: {mode: none}`.
   - Autonomy: allow `github.read-pr` and `github.list-prs`, deny `git.push` and everything else.
   - Prompt: the login, the threshold, `$prs`; read each with `read-pr`, a pull request is stale when the login's review was requested over a day ago and the login has given no review since; answer with the digest.
   - Answer contract: `{stale: !irtype [], digest: !irtype ""}`.
3. `onDone` derives the message the way gate-ask.tony does: under `slack.Signadot.out`, keyed `stale-review-<date>`, `to: user:<email>`, `text: $data.digest`; and patches the day `stage: done`. `onFailed` patches `stage: failed, err: $err`. An empty `stale` writes no message.

**README:** what to change (login, email, hour, threshold, prompt), how to install (`verse charter -a -f …`), how to tick by hand (`verse schedule tick morning --due <instant> --at signadot.stale-review`), and the follow-up that drops the checkout.
