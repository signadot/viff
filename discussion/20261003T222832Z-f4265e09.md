- Rule `main` (subject `git.<repo>.ref.main` with `tree.charters`): derives `state.main {sha, tree}` and `candidate.<tree> {sha, tree}` (id = tree, so one per tree ever seen).

- Rule `install` (subject `state.approved.*`): `!let` reads `state.main`'s tree and sha; fires when `tree` is main's and `installed` is not main's sha; spawns a `calls` task (`run_bash`: `git archive $tree | tar -x` into a temp dir, then `verse c -a <address> -d <dir> --prune`; `$tree` is a top-level field of the subject, and a tree object is the directory's contents whichever commit carries it); `onDone` patches `installed: <main's sha>`, derives `running {sha, tree}`, and the git outbox inputs `{to: branch.verse/live, sha}` (id live, moves) and `{to: tag.live-verse/<tree>, sha: <sha approved at>}` (keyed by the tree, so one tag per tree, at the commit it was approved at; a later commit carrying the same tree moves verse/live and makes no second tag).
- The installed record is therefore: `state.approved.<tree>.installed` (which commit this tree was installed for) + `running`; both written by the package (`running` by derive, `installed` by patch). No seed is needed.
