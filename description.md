# docs: the tutorial landing's left bar lists the four pages

The left column on the site is the page's table of contents. The tutorial landing lists its four pages (data, questions, tasks, charters) in a table, so its left column shows only "Start", and a reader cannot go to a page from it.

The docs landing already solves this: its headings are links, and overrides/toc.html lists such a heading as its link. The tutorial landing takes the same shape: one linked heading per page, after Start.
