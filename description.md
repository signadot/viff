# runnerd's config reference names the verse system a doer's section takes

On #52's config shape, a doer's `systems.verse` section is taken whether or not the runner reaches a verse, and the runner performs `verse` with its own token. docs/reference/runnerd.md's row for `agents.<name>.systems.<system>` / `script.systems.<system>` lists what the runner performs and stops, and does not say so.
